Fast, safe Gradle tuning

How droidperf works

droidperf inspects your Android Gradle builds, highlights bottlenecks, and recommends conservative fixes that are easy to review and safe to roll back.

1. Inspect the build

droidperf reads your build log or audits the project directly to detect slow configuration phases, caching gaps, parallelism issues, and other common hotspots.

2. Recommend targeted fixes

It turns those findings into low-risk actions such as enabling build cache, parallel execution, or better JVM settings in gradle.properties.

3. Verify before shipping

After applying changes, droidperf re-runs Gradle help verification and reverts changes if the build structure becomes invalid.

4. Use it in the CLI or browser

  • CLI: npx droidperf audit /path/to/project
  • Analyze logs: npx droidperf analyze --build-log ./build.log --local
  • Dashboard: npx droidperf ui
