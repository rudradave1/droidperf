# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in `droidperf`, please do **not** open a public GitHub issue.

Instead, report it privately:

- Email: `rudramordan@gmail.com`

Please include:

- A description of the issue and impact
- Steps to reproduce (PoC if possible)
- Your environment (OS, Node version)

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x     | ✅        |
| 0.x     | ❌        |

We’ll acknowledge receipt and work on a fix as quickly as possible.
